An early, small contribution: a DuckDuckGo "Instant Answer" cheat sheet
listing the major Greek gods and their dominions, sourced from
[Wikipedia's list of Greek mythological figures](https://en.wikipedia.org/wiki/List_of_Greek_mythological_figures#Major_gods_and_goddesses).
The whole contribution was a single JSON data file
(`share/goodie/cheat_sheets/json/greek-gods.json`) that DuckDuckGo's existing
cheat-sheet Goodie renders, no template or application code involved. Merged
as [#1427](https://github.com/duckduckgo/zeroclickinfo-goodies/pull/1427).
