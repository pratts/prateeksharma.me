Yolobus operated intercity buses. I worked on the in-house systems for inventory
and bookings.

## Engineering areas

### Global Distribution System

- Designed the **database architecture** for an in-house GDS managing trip
  inventory and real-time bookings.

### Booking engine

- Migrated core services to **Python / Django**.
- Built a **serverless ticket-booking engine** on **AWS Chalice**, improving
  maintainability and transaction scalability.
- Implemented high-throughput booking APIs integrating third-party payment and
  inventory providers (e.g. Redbus, Paytm).

## Stack

Python · Django · AWS Chalice · PostgreSQL · REST APIs
