Adda52 is one of India's largest real-money poker platforms. I joined as a
graduate trainee in 2014 and left in 2020 as a Senior Software Engineer, working
across the game backend, load and resilience testing, and the public platform.

## Role progression

- **Graduate Engineer Trainee** (Sep 2014 – Oct 2015)
- **Software Engineer** (Oct 2015 – Oct 2016)
- **Senior Software Engineer** (Oct 2016 – Feb 2020)

## Engineering areas

### Game logic

- Contributed to core poker cash-game and tournament-management modules.
- Implemented the **OFC** poker variant end to end on the `adda52live.com`
  frontend (Angular 2).

### Load and resilience testing

- Enhanced Java-based user-behaviour simulators to **load test real-time poker
  servers at 10,000+ concurrent users**.
- Built **disaster-recovery systems** for zero-downtime gameplay, restoring
  poker games and player state after a failure.

### Platform migration

- Led migration of the public gaming platform from **PHP to Node.js**, improving
  performance and maintainability.
- Built Angular 2 interfaces for event bookings on `adda52live.com` and
  user-segmentation logic for targeted marketing.

### Delivery

- Developed Gradle-based CI/CD pipelines with **Jenkins**, automating builds and
  reducing integration friction.
- Represented a 6-member team in sprint planning and stakeholder meetings,
  coordinating with QA, product, and DevOps.

## Stack

Java · Node.js · Angular 2 · Jenkins · Gradle
